## Project Overview

**ねれた** (Nereta) is a single-file Japanese sleep tracking PWA. The entire app lives in `nereta.html` — no build step, no dependencies, no package manager. Open the file directly in a browser to run it.

## Architecture

Everything is self-contained in `nereta.html`:

- **Data layer**: `localStorage` under key `nereta-v1`. Schema: `{ pending: {bedtime: ISO} | null, records: [{id, bedtime, waketime, minutes, rating}] }`
- **State**: Two module-level variables — `store` (persisted) and `ratingFor` (transient, post-wake star-rating prompt)
- **UI**: Two tab views (`#view-log`, `#view-graph`). A single `render()` call redraws both. No framework — raw DOM manipulation.
- **Baku mascot**: Inline SVG generated by `bakuSVG(sleeping)` with two eye states.

## Key Data Flow

1. User taps 寝る → `goSleep()` writes `store.pending`, calls `save()` + `render()`
2. User taps 起きた → `goWake()` finalizes record, sets `ratingFor`, calls `render()`
3. Star tap → `setRating()` updates record in-place, clears `ratingFor` if it matches
4. `render()` branches on `store.pending` → `ratingFor` → default (idle) state

## Chart Logic

`periodData(period)` aggregates records into bar data for week/month/year views. Year mode calculates per-night averages per month (using a `seen` dedup map to avoid counting multiple records on the same night as separate nights).

## Locale

All UI text is Japanese. Date/time formatting is manual (no `Intl` API used). Days-of-week array `['日','月','火','水','木','金','土']` is referenced in `renderHist()` and `exportCsv()`.
